# keyboard-workshops.de

Website für Keyboard-Coaching und Workshops von Thorsten Hillmann.

- `index.html` – Startseite mit Anfrage-Assistent (erstellt eine fertige E-Mail, kein Server nötig)
- Datenschutz und Impressum: verlinkt auf die Richtlinien von keyboard-sounds.com

Gehostet über GitHub Pages. Domain wird erst nach Freigabe per `CNAME` und DNS-Umstellung verbunden.
